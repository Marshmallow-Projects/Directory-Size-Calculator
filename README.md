# Directory Size Calculator

**Directory Size Calculator** is a Python script by **Marshmallow.Projects** that calculates the total size of all files in a specified directory and its subdirectories. This tool is useful for monitoring disk usage, checking how much space your files are consuming, and organizing storage.

## Features

- Calculates the total size of all files in a directory.
- Displays the total size in a human-readable format (e.g., KB, MB, GB, TB).
- Easy to use with minimal setup.

## Requirements

- Python 3.x

## Installation

Simply clone or download the repository :)

```bash
   git clone https://github.com/Marshmallow-Projects/directory-size-calculator.git
```
